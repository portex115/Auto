# ТЗ: прямая публикация в TikTok с экраном подтверждения

Цель: перейти от черновиков (inbox) к публикации без ручного шага, соблюдая правила TikTok Direct Post API
(Content Sharing Guidelines). Публикация идёт только после того, как человек в виджете проверил ролик и подтвердил
настройки. Это требование TikTok и условие прохождения аудита.

## Роли и поток

1. Папка с рилсами попадает в `queue/` (как раньше).
2. Для аккаунта с `"mode": "direct"` виджет показывает блок «TikTok: нужно подтвердить» (ролики без `*.tiktok.json`).
3. Экран «Публикация в TikTok»: ник автора, превью видео, название, приватность без значения по умолчанию,
   комментарии/дуэт/сшивание (выключены по умолчанию, недоступные серые), раскрытие коммерческого контента,
   согласие (Music Usage Confirmation, при брендированном ещё Branded Content Policy), явное подтверждение.
4. Виджет коммитит `queue/<папка>/<ролик>.tiktok.json` в репозиторий.
5. Автопостер в своё время (по плану дня) читает файл и вызывает `/v2/post/publish/video/init/` ровно с этими
   настройками, затем опрашивает статус.
6. Нет файла подтверждения: ролик уходит в черновики (inbox), а не публикуется молча.

## Требования (чек-лист TikTok) и где реализовано

| Требование | Где |
|---|---|
| Показать ник автора из `creator_info` | `tiktok_creator.json` (stats-шаг), `renderer/app.js` `openTt` |
| Приватность только из `privacy_level_options`, без значения по умолчанию | `openTt` (пустой пункт «— выберите —»), `tt_post_info` |
| Комментарии/дуэт/сшивание выключены, серые если отключены автором | `openTt`, `toSettings`, `tt_post_info` |
| Коммерческий контент: Your brand / Branded, обязательный выбор, branded не приватный | `ttSync`, `validate`, `tt_post_info` |
| Метка о платном партнёрстве и согласие с политиками | `ttSync` (`#ttCommNote`, `#ttConsent`) |
| Превью видео, редактируемое название | `#ttVideo`, `#ttTitle` |
| Явное согласие пользователя до отправки | `#ttAgree`, поле `consent` в JSON, проверка в Python |
| Предупреждение, что обработка занимает минуты | текст на экране, `wait_ready` |
| Опрос статуса | `TikTok.wait_ready` |
| Нет подтверждения → не публиковать в профиль | `TikTok.upload` (fallback в inbox) |

## Риски

- Аудит не гарантирован: правила TikTok называют неприемлемым «инструмент для загрузки на свои аккаунты».
  Пока приложение не прошло аудит, все публичные ролики будут `SELF_ONLY`, а аккаунт должен быть закрытым.
- Один файл настроек на ролик: при нескольких TikTok-аккаунтах они получат одинаковые настройки.
- Токен refresh живёт 365 дней; новый сохраняется в `TT_TOKEN_<ИМЯ>` автоматически (нужен `GH_PAT`).
