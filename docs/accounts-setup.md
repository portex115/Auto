# Аккаунты: добавить кнопкой, много сразу, своя копия для друга

С виджета 4.1 аккаунт добавляется кнопкой **«+ аккаунт»** в разделе TikTok или Instagram. Виджет сам:

1. открывает окно входа в соцсеть (каждый раз чистое, поэтому можно добавлять аккаунты подряд);
2. получает токен и сразу кладёт его в секрет GitHub (`TT_TOKEN_<НИК>` или `IG_TOKEN_<НИК>`); токен шифруется
   на компьютере ключом репозитория, в открытом виде он никуда не уходит и в окне виджета не появляется;
3. дописывает аккаунт в `config.json` (если это тот же аккаунт, что уже был, просто обновляет вход);
4. если в репозитории ещё нет общих секретов `TT_CLIENT_SECRET` и `GH_PAT`, сохраняет и их.

Дальше токены продлеваются сами: TikTok при каждом запуске автопостера (вход живёт год), Instagram раз в неделю
(workflow «Продление токена», теперь для всех аккаунтов). У каждого аккаунта в виджете цветная точка:
зелёная = работает, жёлтая = вход скоро истечёт, красная = токен не работает, серая = ещё не проверялся.
Нажми на аккаунт: там «Переподключить» и «Убрать».

## Один раз: подготовка

**Токен GitHub виджета** (github.com/settings/personal-access-tokens → твой токен → Edit): к прежним правам
Contents и Actions добавь **Secrets: Read and write**. Без него виджет не сможет сохранить вход.

**TikTok.** В виджете: «+ аккаунт» в разделе TikTok → вставь **Client secret** приложения
(developers.tiktok.com → Manage apps → приложение → если работаешь в песочнице, вкладка Sandbox → Client secret)
→ «Сохранить ключ». Ключ хранится зашифрованным только на этом компьютере.

**Instagram** (только если хочешь добавлять Instagram кнопкой; старые аккаунты работают как раньше):
1. developers.facebook.com → приложение Auto → Instagram → «Настройка API со входом через Instagram».
2. В «Настройках входа для бизнеса» добавь адрес перенаправления OAuth: `https://frizy229.github.io/autopostreels/`.
3. Скопируй **ID приложения Instagram** и **секрет приложения Instagram** в виджет (Настройки → «Ключи Instagram»).
4. Пока приложение в режиме разработки: Роли приложения → Роли → **Тестировщики Instagram** → добавь аккаунт;
   владелец аккаунта принимает приглашение в Instagram (Настройки → Приложения и сайты → Приглашения тестировщика).

Если готовый токен уже есть (например, из «Сгенерировать маркер» в кабинете Meta), его можно вставить в
«Есть готовый токен Instagram?» вместо входа.

## Несколько TikTok-аккаунтов подряд

Пока приложение TikTok не прошло проверку, оно работает в песочнице: войти можно только аккаунтами из списка
**Target users**. Поэтому:

1. developers.tiktok.com → приложение → **Sandbox** → **Target users** → добавь все новые аккаунты
   (если TikTok попросит, войди в каждый и подтверди).
2. В виджете, раздел TikTok: **«+ аккаунт» → «Войти в TikTok» → войти → «Разрешить» → проверить ник → «Сохранить аккаунт»**.
3. **«Добавить ещё»** и повторить для следующего. На каждый аккаунт меньше минуты.
4. Ник лучше писать настоящий: так будут называться подпапки аккаунта в папке дня (`queue-tiktok/007_x/<ник>/…`)
   и блоки подписей `REELS CAPTION (TikTok @ник):`.

Режим у новых аккаунтов: **черновики** (ролик приходит уведомлением в TikTok, публикуешь сам; 5 неопубликованных
черновиков в сутки на аккаунт). «Сразу (после аудита)» включай, только когда приложение пройдёт аудит Direct Post:
без него TikTok показывает ролик только владельцу.

Если окно входа не открывается: «Войти через браузер», войди, скопируй адрес из строки браузера и вставь в виджет.
Перед следующим аккаунтом выйди из TikTok в браузере.

Когда приложение TikTok пройдёт проверку (Production), список Target users больше не нужен: подключается любой аккаунт.

## Своя копия для друга (его аккаунты, не твои)

Схема: у друга **свой репозиторий** (копия кода) со **своими секретами** и свой виджет. Секреты GitHub при копировании
не переносятся вообще, поэтому твои токены друг не увидит, а его токены не увидишь ты. Приложения TikTok и Meta
можно использовать твои: тогда друг ничего не регистрирует, а ты только добавляешь его аккаунты в тестировщики.

**Ты (Alex), один раз:**
1. Репозиторий autopostreels → Settings → General → отметь **Template repository**.
2. Добавь аккаунты друга: TikTok в Sandbox → Target users; Instagram в «Тестировщики Instagram» (см. выше).
3. Передай другу лично (не в общий чат): Client secret TikTok, и если нужен Instagram, ID и секрет приложения Instagram.
   Это ключи твоих приложений: кто их знает, может входить от имени приложения, поэтому только тем, кому доверяешь.

**Друг:**
1. Открыть https://github.com/Frizy229/autopostreels → **Use this template → Create a new repository** →
   имя любое, **Public** (иначе Instagram не скачает обложки) → Create.
2. Токен GitHub: github.com/settings/personal-access-tokens → Generate new token → Only select repositories → свой
   репозиторий → права **Contents, Actions, Secrets: Read and write** → Generate → скопировать.
3. Поставить виджет (`ReelsWidget-Setup.exe` из Releases Alex: https://github.com/Frizy229/autopostreels/releases/tag/widget).
   Настройки → Репозиторий: `<ник-друга>/<имя-репозитория>` → вставить токен → «Сохранить и проверить».
4. Настройки → «Своя копия автопостера» → вписать имя репозитория → **Очистить копию**. Из копии уйдут очереди,
   история и аккаунты Alex (остаются код, расписание и ключ приложения TikTok).
5. Настройки → «Ключ TikTok» (и «Ключи Instagram») → вставить ключи от Alex.
6. В разделах TikTok и Instagram: **«+ аккаунт»** → войти в свои аккаунты.
7. Часовой пояс и окно публикаций: в `config.json` своего репозитория (`timezone`, `day_start`, `day_end`).

Расписание у друга работает от GitHub (каждые 10 минут, GitHub иногда пропускает запуски). Если нужно точнее,
как у Alex: бесплатный будильник cron-job.org, который раз в 5 минут запускает workflow «Публикация рилсов»
(со своим токеном GitHub друга, право Actions: Read and write).
