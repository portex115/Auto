## 2026-11-06 · Виджет 4.1.0: аккаунты кнопкой и копия для друга

Alex: «Планирую добавить ещё TikTok-аккаунтов, как делать это проще?» и «хочу выдать другу софт, но чтобы у него были его аккаунты».
- Кнопка «+ аккаунт» в разделах TikTok и Instagram: вход в соцсеть в отдельном чистом окне (или через браузер),
  токен сразу шифруется ключом репозитория и сохраняется в секрет GitHub, аккаунт дописывается в `config.json`.
  Недостающие общие секреты (`TT_CLIENT_SECRET`, `GH_PAT`) сохраняются тоже. Ключи приложений хранятся только на компьютере (DPAPI).
- Состояние аккаунта: точка у ника (работает / скоро истечёт / не работает / не проверялся), «Переподключить», «Убрать».
  Автопостер пишет состояние токенов в `state.json → tokens` (только при изменении).
- Instagram: вход через Instagram Login (токены IGAA, 60 дней) или готовый токен. «Продление токена» теперь продлевает все аккаунты Instagram.
- Копия для друга: шаблон репозитория, свой токен и секреты, кнопка «Очистить копию» (очереди, история, аккаунты Alex).
  В основном репозитории Alex кнопка скрыта и запрещена. TikTok может быть первым аккаунтом (копия только с TikTok).
- Инструкция: [accounts-setup.md](accounts-setup.md). Новому токену виджета нужно право Secrets: Read and write.
Тесты: Python 101, виджет 7 наборов (новый `accounts.test.js`: шифрование секрета, config.json, вход, состояние, чистый старт).
Окно входа проверено в настоящем Electron на поддельной странице входа (код перехватывается, чужой state отклоняется).

## 2026-11-05 · Reels Studio 0.1.0: приложение нарезок (studio-app/)

Запрос Alex: отдельное приложение для Windows, которое ищет лонги и моменты, пересобирает их в вертикаль 9:16,
делает субтитры со стилями, монтирует под N каналов (N в настройках = число разных нарезок) и кладёт результат
в формате папок автозалива. Примеры: нарезки стримов Эвелона (вебка сверху, контент снизу, крупные цветные субтитры).
Ответы Alex: искать везде, главное лицо Эвелон; ключей API нет; каждому TikTok своё видео, можно один момент
в разных форматах; субтитры русские с подсветкой; обязательно `#evelone` и `twitch: evelone2004`; видеокарта RTX 3070.

Что сделано (Electron 33, без фреймворка, стекло Windows 11, шрифт Onest, иконки Lucide):
- Поиск: YouTube и записи Twitch через yt-dlp, быстрые кнопки под Эвелона, фильтр «от N минут», файлы с диска и ссылки.
- Моменты без ИИ: громкость относительно фона вокруг (смех, крики), плотность чата Twitch/YouTube со сдвигом на реакцию,
  отрезки 20–60 с с подводкой. Для ссылок сначала качается только звук, видео — лишь нужные куски.
- Рамка вебки: на кадре двигаешь две рамки (вебка, контент), автопоиск лица, запоминание по стримеру.
- 5 раскладок: реакция сверху/видео снизу; стрим сверху/мини-игра снизу (папка с играми); по центру с размытым фоном;
  вебка крупно с окном видео; обрезка 9:16. 10 стилей субтитров со словом-подсветкой, 3 стиля заголовка на стыке.
- Каналы: раскладка и стиль субтитров по кругу; моменты раздаются «змейкой» по силе; если моментов мало, момент
  повторяется у другого канала в другой раскладке и стиле, но никогда дважды в одном канале. Мелкие отличия: зум, цвет, скорость.

- Выход: `queue/NNN_имя/<аккаунт>/short-N-*.mp4 + .txt + cover-N.jpg`, `texts.json` с комментарием, номер папки по порядку.
  Один канал — плоская папка. NVENC с откатом на процессор, громкость −14 LUFS.

Тесты: 10 наборов `studio-app/test` (`npm test`), включая сквозной на настоящем ffmpeg (файл → моменты → проверка → 2 канала → папка).

Автопостер (`autoposter.py`):

  Старые записи не трогаются, общая очередь хранится как раньше.

- `--only` и `remove` понимают приставки очередей; `dry-run` показывает все очереди, подписи и комментарии.
