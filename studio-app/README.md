# Reels Studio

Приложение для Windows: из записи стрима делает вертикальные нарезки для TikTok и Reels и складывает их
в папку, которую понимает автозалив этого репозитория.

**Скачать:** [Releases → studio → ReelsStudio-Setup.exe](https://github.com/Frizy229/autopostreels/releases/tag/studio).
Установщик собирается из `main` workflow «Сборка Reels Studio для Windows».

## Первый запуск

1. **Настройки → Компоненты:** скачай yt-dlp, whisper.cpp и модель речи (`large-v3-turbo`, 1.6 ГБ, для RTX 3070).
   ffmpeg уже внутри. Нажми «Проверить» у кодировщика NVIDIA: если не работает, выбери «Процессор».
2. **Монтаж:** отметь раскладки и стили субтитров. Для раскладки «Стрим сверху, мини-игра снизу» выбери папку
   со своими роликами мини-игр (Subway, паркур, Minecraft и т. п.).
3. **Каналы и тексты:** число каналов, их имена (как аккаунты в автозаливе), роликов на канал, подписи, комментарий.

## Как делать нарезки

1. **Поиск:** быстрые кнопки «Записи стримов Twitch», «YouTube: эвелон стрим»… или своя ссылка, или файл с диска.
   «В работу» добавляет видео в «Моменты».
   Если YouTube пишет «Sign in to confirm you're not a bot», войди в YouTube в Firefox, закрой Firefox и повтори.
   Программа сама подхватит cookies; браузер или файл cookies.txt можно выбрать в Настройках → «Вход в YouTube».
   Twitch и файлы с диска работают без входа.
   Если YouTube не открывается вообще («Failed to resolve www.youtube.com»), включи VPN. Программа сама берёт прокси, который VPN ставит в Windows.
   Если VPN работает только в браузере, укажи его прокси в Настройках → «Сеть» и нажми «Проверить YouTube».
1a. **Фон:** залипательные видео и мини-игры для низа (чистка ковров, ржавое, слаймы…). Выбери превью и нажми
   «В библиотеку»: видео скачается в папку фона, монтаж возьмёт его сам. «Только Creative Commons» — меньше риска жалоб.
2. **Моменты:** «Рамка вебки» (зелёная — лицо, пунктир — контент; «Найти лицо» ставит рамку сама).
   «Найти моменты» слушает звук и чат и предлагает отрезки. Впиши заголовки («строка 1 | строка 2»),
   сними лишнее, отметь «Эвелон главный», нажми «Проверить» (распознаёт речь и проверяет правила).
3. **Сборка:** «Собрать N роликов». Готовая папка — в «Документы/Reels Studio/queue/NNN_имя/».
   Её можно загрузить виджетом как обычную папку.

## Что внутри папки

```
queue/017_evelone-stream/
  texts.json                 ← комментарий для всех роликов (Instagram)
  evelon185/                 ← канал 1: свои ролики
    short-1-kontrataka.mp4   1080×1920, 30 к/с, H.264, AAC, −14 LUFS
    short-1-kontrataka.txt   TITLE / REELS CAPTION (Instagram) / REELS CAPTION (TikTok) / COVER
    cover-1.jpg
    …
  channel2/ …
```

При одном канале подпапок нет. В каждой подписи и в TITLE обязательно есть `#evelone` и `twitch: evelone2004`
(меняется в «Каналы и тексты → Правила конкурса»).

## Правила конкурса

Перед сборкой каждый выбранный момент проверяется: в нём должна звучать речь (по умолчанию не меньше 25% времени
и 12 слов, иначе «молча смотрит»), у раскладок с вебкой должна быть задана рамка вебки. Не прошедшие моменты
в папку не попадают и перечислены в окне сборки. Что именно Эвелон «главное лицо» и мем оригинальный, программа
проверить не может: для этого галочка «Эвелон главный» и переключатель «Только отмеченные мной».

## Для разработки

```
cd studio-app
npm install
npm start          # окно
npm test           # 12 наборов: раскладки, субтитры, моменты, каналы, выход, правила, источники, речь, рендер,
                   # настройки, окно, компоненты; сквозной тест конвейера на настоящем ffmpeg (Linux/macOS)
npm run icons      # обновить иконки Lucide в renderer/icons
```

Код: `lib/` — чистая логика (раскладки `layout.js`, субтитры ASS `subs.js`, моменты `moments.js`, раздача по каналам
`plan.js`, выходная папка `output.js`, правила `rules.js`, yt-dlp `sources.js`, whisper.cpp `transcribe.js`,
ffmpeg `render.js`, конвейер `pipeline.js`), `main.js` — окно и задачи, `renderer/` — интерфейс.
Снимки всех страниц: `STUDIO_SHOTS=папка npm start`.
История: [docs/WORKLOG.md](../docs/WORKLOG.md), баги: [docs/BUGFIXES.md](../docs/BUGFIXES.md).
Шрифты субтитров (Montserrat, Unbounded, Rubik, Russo One) и иконки Lucide — под открытыми лицензиями OFL/ISC.
